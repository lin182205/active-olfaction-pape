# 摘 要

气味源定位在危险气体泄漏检测、火灾早期预警、环境监测以及灾害救援等场景中具有重要意义。传统电子鼻通常采用固定安装的气体传感器，其采样位置随机器人本体被动变化，难以主动改变空间采样几何；另一方面，金属氧化物气体传感器具有响应滞后、恢复缓慢、基线漂移和噪声等特性，而真实湍流羽流又呈现明显的时空间歇性，使得瞬时浓度梯度并不稳定。针对上述问题，本文提出一种基于深度强化学习的双触须自适应嗅觉搜索方法：在移动机器人左右两侧布置可独立摆动的嗅觉触须，将机器人运动与左右触须采样位置作为统一决策变量，并以近端策略优化（Proximal Policy Optimization, PPO）实现联合策略学习。为保证算法具有真机部署可行性，观测仅由真实硬件可获得的信息构成，包括双路气体传感器的相对信号、平滑量、短时趋势、左右差分、触须角度与扇区、机器人航向、上一时刻移动动作以及失嗅持续时间，不向策略输入真实气源位置、真实风向或到源距离等仿真特权量。针对气体传感器的慢响应特性，本文进一步使用固定长度历史窗口，并比较 MLP、GRU 与 Transformer 三类时序编码结构；当前实现以 GRU 作为默认时序编码器，同时保留 Transformer 自注意力分析接口。在奖励设计方面，采用距离差分、历史最佳浓度增量、触须独立重捕获奖励、时间成本、停滞惩罚、到源奖励与越界惩罚组成的复合奖励，并通过“仅奖励历史最佳浓度提升”和“限制重捕获奖励次数”等机制降低原地停留、旋转或维持高浓度所造成的奖励投机。仿真环境采用动态 puff 羽流，显式描述羽流团释放、随风输运、横纵向扩散、质量衰减、风向蜿蜒及小尺度湍流扰动，并引入非对称气体传感器响应和可选域随机化，从而形成与真实主动嗅觉搜索更接近的部分可观测决策问题。本文给出完整的系统建模、Actor–Critic 网络、PPO 数学推导、奖励函数、训练流程以及仿真优化方案，并设计后续消融实验和基线对比方案，为进一步完成真实机器人验证与论文定量实验提供统一方法框架。

# 符号与缩略语说明

| **符号/缩写** | **含义**                                                                 |
|---------------|--------------------------------------------------------------------------|
| OSL           | Odor Source Localization，气味源定位                                     |
| POMDP         | Partially Observable Markov Decision Process，部分可观测马尔可夫决策过程 |
| PPO           | Proximal Policy Optimization，近端策略优化                               |
| GAE           | Generalized Advantage Estimation，广义优势估计                           |
| A–C           | Actor–Critic，策略网络—价值网络结构                                      |
| H             | 历史观测窗口长度，当前训练脚本默认 H=20                                  |
| d_t           | 机器人在 t 时刻到气源的欧氏距离，仅用于训练奖励和评估                    |
| c_t^L,c_t^R   | 左右触须位置处经传感器动态后的读数                                       |
| b_t           | 失嗅持续时间（blank age）                                                |
